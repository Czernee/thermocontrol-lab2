# ТермоКонтроль - лабораторная работа 2

Учебная программная часть информационной системы мониторинга температуры
помещения. Ядро не зависит от конкретного мессенджера: внешний адаптер передает
в приложение идентификатор канала и команду пользователя.

Реализовано:

- виртуальный датчик температуры с периодом 1 с и шагом 0,1 °C;
- проверка диапазона -40...85 °C;
- буфер до 300 допустимых отсчетов;
- скользящее среднее по пяти последним отсчетам;
- SQLite и шифрование измерений AES-GCM;
- вход по логину и паролю, PBKDF2-HMAC-SHA-256, временные сессии;
- отдельная проверка права пользователя на датчик через подписку;
- команды `/start`, `/status`, `/history`, `/limits`, `/logout`;
- автоматические тесты.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py --demo
python -m unittest -v
```

Для интерактивной работы сначала создайте локальную учетную запись:

```powershell
python main.py --create-user student
python main.py
```

Пароль не выводится на экран и не хранится в открытом виде. Файлы базы и ключа
создаются локально и исключены из репозитория.
